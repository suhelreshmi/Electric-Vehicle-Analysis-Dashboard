# Electric-Vehicle-Analysis-Problem-Statement

## Project Overview

This project presents an interactive Electric Vehicle (EV) Analysis Dashboard developed in Microsoft Power BI using the Electric Vehicle Population Dataset.

The dashboard provides insights into EV adoption trends, manufacturer dominance, vehicle distribution across states, CAFV eligibility, and electric range analysis. It includes data cleaning, transformation, KPI reporting, interactive visualizations, and navigation between dashboard pages.

## Business Objective

The objective of this project is to analyze the electric vehicle market by:

Understanding overall EV adoption.
Comparing Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
Analyzing EV growth trends over time.
Identifying leading manufacturers and vehicle models.
Evaluating CAFV (Clean Alternative Fuel Vehicle) eligibility.
Examining geographic distribution of EVs across states.
